# 蘑米虚拟伴游 Demo

老师可直接打开线上页面体验（建议使用 Chrome 或 Edge）：

**https://blaze-Lin16.github.io/virtual-pet-demo/**

## 如何体验

1. 用电脑打开上方链接（摄像头和手势需要电脑摄像头）。
2. 点击「遇见你的伙伴」，再点击「进入伴游视野」。
3. 浏览器弹出摄像头权限时选择「允许」。
4. 点击「开启手势跟随」，等待模型加载后把手伸进画面。
5. 也可以用鼠标拖动蘑米、点击场景移动、摸头、休息、制作明信片。

## 说明

- 本页通过 GitHub Pages 以 HTTPS 提供，满足浏览器摄像头安全要求。
- 首次开启手势会从网络加载 MediaPipe 模型，需要能访问 jsDelivr 与 Google 模型资源。
- 没有摄像头时，仍可用页面里的模拟背景和鼠标交互。
